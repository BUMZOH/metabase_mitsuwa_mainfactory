# コールバック関数の基礎知識

作成日: 2026-08-02

------------------------------------------------------------------------

# はじめに

Pythonを勉強していると、突然次のようなコードが現れます。

``` python
pattern.sub(replace, url)
```

あるいは

``` python
button.clicked.connect(on_clicked)
```

さらに

``` python
page.on("response", handle_response)
```

これらはすべて **コールバック関数** を利用しています。

最初は「関数を呼んでいないのに、なぜ実行されるの？」と感じます。

この教材では、コールバック関数を基礎から解説します。

------------------------------------------------------------------------

# コールバック関数とは

コールバック関数とは、

> **「あとでライブラリや他のプログラムから呼び出してもらうために渡す関数」**

です。

自分で呼ぶのではなく、**相手が必要になったタイミングで呼びます。**

------------------------------------------------------------------------

# 普通の関数との違い

普通の関数

``` python
def hello():
    print("こんにちは")

hello()
```

自分で `hello()` を呼びます。

一方、コールバックでは

``` python
library(hello)
```

のように **関数そのもの** を渡します。

ライブラリが必要になったら

``` python
hello()
```

を実行してくれます。

------------------------------------------------------------------------

# イメージ

``` text
あなた
  │
  │ 関数を渡す
  ▼
ライブラリ
  │
  │ 必要になったら
  ▼
あなたの関数を呼ぶ
```

------------------------------------------------------------------------

# pattern.sub() の場合

``` python
def replace(match):
    return f"{match.group(1)}machine_no=3"

pattern.sub(replace, url)
```

内部ではイメージとして

``` python
match = Matchオブジェクト
replace(match)
```

が実行されています。

つまり `match` は **sub() が作って渡している引数** です。

------------------------------------------------------------------------

# なぜ match が突然現れるの？

`match` は予約語ではありません。

``` python
def replace(hoge):
    ...
```

でも動きます。

ただし、渡されるのは Match オブジェクトなので、多くの人が `match`
という名前を使っています。

------------------------------------------------------------------------

# JavaScriptでも同じ

``` javascript
button.addEventListener("click", onClick);
```

ボタンが押されると

``` javascript
onClick(event);
```

をブラウザが呼びます。

`event` もブラウザが作って渡しています。

------------------------------------------------------------------------

# Playwrightでも同じ

``` python
page.on("response", handle_response)
```

レスポンスを受信すると

``` python
handle_response(response)
```

が自動で呼ばれます。

------------------------------------------------------------------------

# Tkinterでも同じ

``` python
button = tk.Button(
    root,
    text="実行",
    command=run,
)
```

クリックすると

``` python
run()
```

が自動で実行されます。

------------------------------------------------------------------------

# コールバック関数の特徴

-   自分では呼ばない
-   ライブラリへ渡す
-   必要なタイミングで実行される
-   必要ならライブラリが引数も渡してくれる

------------------------------------------------------------------------

# よく使う場面

-   ボタンのクリック
-   キー入力
-   マウス操作
-   タイマー
-   正規表現の置換
-   Playwrightのイベント
-   Flaskのルーティング（考え方は近い）

------------------------------------------------------------------------

# まとめ

コールバック関数とは、

> 「あとで呼び出してください」とライブラリへ預ける関数

です。

ライブラリは必要になったらその関数を呼び出します。

必要な情報があれば、`match` や `event`
のような引数も自動で渡してくれます。

この考え方を理解すると、PythonだけでなくTkinter、Playwright、JavaScriptなどのイベント処理も理解しやすくなります。
