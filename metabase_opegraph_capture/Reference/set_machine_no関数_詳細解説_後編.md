# `set_machine_no()` 関数 詳細解説（後編）

作成日: 2026-08-02

------------------------------------------------------------------------

# 31. machine_no が存在しない場合

前編では、URL内に `machine_no` が存在する場合の置換処理を学びました。

存在しない場合は、次のコードが実行されます。

``` python
separator = "&" if "?" in url else "?"
return f"{url}{separator}machine_no={machine_no}"
```

目的は **URLの末尾へ `machine_no` を追加すること**です。

------------------------------------------------------------------------

# 32. 三項演算子

``` python
separator = "&" if "?" in url else "?"
```

これは if 文を1行で書いたものです。

通常の if 文では次のようになります。

``` python
if "?" in url:
    separator = "&"
else:
    separator = "?"
```

意味は、

-   URLに `?` がある → すでにクエリパラメータがある → `&` を使う
-   URLに `?` がない → 最初のパラメータ → `?` を使う

------------------------------------------------------------------------

# 33. `"?" in url`

``` python
"?" in url
```

これは文字列に `?` が含まれているか調べています。

例:

``` python
"?" in "http://localhost"
```

結果

``` python
False
```

例:

``` python
"?" in "http://localhost?date=2026-08-02"
```

結果

``` python
True
```

------------------------------------------------------------------------

# 34. f文字列でURLを組み立てる

``` python
return f"{url}{separator}machine_no={machine_no}"
```

例えば

``` python
url = "http://localhost/dashboard/5"
separator = "?"
machine_no = 3
```

結果は

``` text
http://localhost/dashboard/5?machine_no=3
```

となります。

------------------------------------------------------------------------

# 35. return の役割

`return` は値を返すだけではありません。

**関数を終了する**役割もあります。

そのため、この関数では

``` python
if pattern.search(url):
    return ...
```

が実行されると、その下の追加処理は実行されません。

------------------------------------------------------------------------

# 36. 処理全体の流れ

``` text
URLを受け取る
        │
        ▼
machine_no を検索
        │
   ┌────┴────┐
   │         │
見つかった  見つからない
   │         │
置換する     URL末尾へ追加
   │         │
   └────┬────┘
        ▼
 新しいURLを返す
```

# 39. 改良案

今回の関数は十分実用的ですが、Pythonには URL を扱うための標準ライブラリ
`urllib.parse` もあります。

URLを正しく解析・編集する必要がある場合は、こちらを使う方法もあります。

一方、このアプリのように **`machine_no`
を変更するだけ**であれば、現在の実装はシンプルで読みやすく、十分実用的です。

------------------------------------------------------------------------

# 40. まとめ

この関数がやっていることは、たった2つです。

``` text
① machine_no があれば置換する

② machine_no がなければ追加する
```

そのために

-   正規表現
-   `search()`
-   `sub()`
-   `lambda`
-   三項演算子
-   f文字列

を組み合わせています。

最初は難しく見える関数ですが、1行ずつ分解すると、それぞれはシンプルな処理の組み合わせです。

このように「複雑そうなコードを小さな処理へ分解して理解する」ことは、Pythonを学ぶ上で非常に重要な考え方です。
